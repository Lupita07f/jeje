Proyecto Integrador

Pokédex Preparatoria

Desarrollo acumulativo de una aplicación web interactiva que conecta con servidores externos en tiempo real. Un proyecto que unifica la maquetación estructural, el diseño responsivo avanzado y la programación asíncrona.

1. Entorno de Desarrollo (Sublime Text)

Fase 01

Estructura y maquetación responsiva

Se utilizó el entorno de desarrollo Sublime Text para construir los cimientos del ecosistema web mediante el archivo index.html. Se definió un contenedor semántico principal (<main id="pokedex-container">) y una barra superior destinada al motor de búsqueda de los Pokémon mediante un elemento de entrada de texto.

Posteriorments, mediante la hoja de estilos style.css, se implementó el modelo de maquetación CSS Grid en la clase .pokedex. Utilizando la propiedad grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));, se logró que la interfaz fuera completamente responsiva y adaptable a cualquier resolución de pantalla de manera automática.

Evidencia: Estructura semántica en index.html
Evidencia: Reglas de CSS Grid en style.css
Fase 02

Lógica con Arreglos y Renderizado Dinámico

Con la estructura visual lista, se inicializó el comportamiento dinámico programando el script app.js. Para asentar las bases del manejo de datos, se estructuró un arreglo de objetos local llamado pokemonsPrueba que contenía información inicial estática (Bulbasaur, Charmander y Squirtle).

Haciendo uso del método forEach y de los Template Literals, se creó la función crearTarjetaHTML(pokemon). Esta rutina inyecta de forma automatizada las etiquetas, imágenes oficiales desde los repositorios y clases de tipos directamente en el DOM, optimizando la escalabilidad del sitio.

Evidencia: Ciclos e inyección dinámica con app.js

2. Control de Versiones y Hosting (GitHub)

Fase 03

Despliegue e interfaz final de la Pokédex

El ciclo completo del software concluyó con la migración del código desde el entorno local hacia la nube. Los archivos fuentes fueron cargados en un repositorio público en GitHub bajo el control de versiones.

Posteriormente, se configuró la herramienta nativa GitHub Pages desde el menú de Settings de la plataforma, permitiendo compilar y desplegar los archivos estáticos de forma gratuita para generar un enlace URL web totalmente público y funcional en internet.

Evidencia: Ajustes de hosting en GitHub Pages
